# 雪乃足球研究室｜可审计的预测工作流可靠性

这是已获作者批准公开的求职作品展示目录。展示完整项目的工程案例，并提供可运行的来源发现组件。它不是完整生产软件，不包含私人v4.51规则、数据库、登录状态或历史模型报告。

## 项目解决什么问题

把官方赛程、可信来源核验、人工授权的模型分析、草稿、不可变封存、官方90分钟赛果结算与静态分享连接起来。重点不是保证比赛预测正确，而是防止软件丢失有效结果、重复消耗模型额度、错误采用赛后资料或发布私人内容。

## 真实工程案例

2026-10-28原17场批次首轮完成8场。5场通过有原始证据支持的映射修复恢复资料，4场由助手补充可信单场链接，最终17/17赛前封存并公开。这个结果经过助手介入，不能当作无人值守一次成功率100%的证据。

后续v0.15.31在恢复链路加入本仓库展示的可信来源发现组件：从已审核球队ID读取赛程、找到精确对阵链接，再交回正式校验器。4场当时仍未开赛的来源可用性回放从0/4到4/4，无新模型调用；不追认原首次执行成功，不代表收益提高。

## 运行组件测试

安装Node.js 24以上，运行 `npm test`。无第三方依赖，无需账号、不联网、不调用模型。测试使用模拟页面与未来测试时间，不能当成真实比赛或回测样本。

`src/ai/trusted-fixture-discovery.mjs`与生产组件保持原始字节一致。相邻的两个资料适配器是公开演示实现，不是完整身份验证器；本目录只验证来源线索发现，不能据此授予正式预测资格。生产系统仍须核验赛事、数值球队ID、时间、原文、独立机构、分析资料、调用授权和采用前版本。

## 工程重点

- 分离模型权限：手动预测、长期review、shadow分别授权；失败/不确定调用计入审计。
- 复用保存回答、零模型复核和有限恢复，避免对不确定发送盲目重试。
- 预测采用前再次检查开赛、委托版本及封存状态。
- 将发布业务快照与展示日期分离，跨午夜仍可审计恢复。
- 运行构建指纹、配置指纹、SQLite在线备份和受控回滚。

## 个人贡献与开发方式

这是持续迭代的个人项目，采用AI辅助开发。项目工作涉及需求界定、实际失败案例分析、权限与数据边界设计、测试审查、实机验收和生产运行。不能把AI生成代码说成全部手写，也不能把语言模型复盘模块说成已经训练了一个更准的足球模型。

## 局限与后续

完整软件依赖Windows、Node、Edge和合法模型账号。新球队映射、网页变动、官方额度和真实证据不足仍可能阻断出分。连续独立批次的一次完成率尚待持续观察；准确率改进和TOP3筛选优势尚未得到独立验证。本脱敏目录已获作者明确批准公开；尚未选定开源许可证，完整私人软件与规则未公开。
